Convolutional Neural Networks (CNNs) are neural networks designed to take advantage of local structure in data. They are especially useful for images because nearby pixels are related, and the same visual pattern can appear in many different locations. Instead of giving every neuron a separate weight for every pixel, CNNs use small filters that are reused across the input. This gives CNNs two of their main properties: **sparse connectivity** and **parameter sharing**.

---

## 2. What CNNs Can Do

CNNs are commonly used for several computer vision tasks. In **image classification**, the goal is to assign a label to an entire image, such as deciding whether an image contains a cat or a dog. In **object detection**, the model must both recognize objects and locate them in the image. In **object segmentation**, the model assigns labels at the pixel level so that the shape of each object can be separated from the background.

Although these tasks have different outputs, they share the same basic challenge: the model needs to recognize useful visual patterns even when the object changes position, lighting, contrast, or viewpoint.

## 3. Why Images Are Difficult

The same object can look very different under different lighting conditions, from different viewpoints, or after a simple translation in the image. A fully connected network can still be applied to images, but full connectivity becomes expensive very quickly.

For example, a color image of size \(3 \times 200 \times 200\) contains 120,000 input values. A single neuron in the first fully connected hidden layer would therefore require 120,000 separate weights. If the layer contains many neurons, the parameter count becomes very large.

CNNs address this problem by using local connections and shared parameters.

## 4. Convolutional Neural Network Basics

### 4.1 Filters, Kernels, and Feature Maps

A CNN learns small sets of weights called **filters** or **kernels**. Rather than learning a different set of weights for every image location, the same kernel slides across the input.

At each location, the kernel looks at a small local patch of the input. This local patch is the kernel's **receptive field** at that position. The weighted result becomes one value in an output **feature map**.

A useful way to think about a kernel is as a learned feature detector. If a detector recognizes a useful pattern in the upper-left part of an image, the same detector may also recognize that pattern in another location.

### 4.2 Multiple Channels

An input can have more than one channel. A grayscale image has one channel, while a standard color image usually has three. A convolutional layer can also learn multiple filters, with each filter producing its own feature map.

This means one layer can learn several types of local patterns at the same time. Earlier layers may respond to simple local structures, while deeper layers combine these patterns into more global structures.

### 4.3 Sparse Connectivity

A fully connected neuron uses every value from the previous layer. A convolutional unit is different: it is connected only to the values inside its local receptive field.

This is called **sparse connectivity**. It greatly reduces the number of connections compared with a fully connected layer.

### 4.4 Parameter Sharing

The same kernel weights are reused at many spatial positions. This is called **parameter sharing**.

Parameter sharing reduces the number of trainable parameters and allows the same learned detector to be applied throughout the input. This is one reason CNNs are effective when a feature can appear in different locations.

### 4.5 Receptive Fields Grow with Depth

Even though an individual convolution only sees a small local region, stacking convolutional layers increases the effective receptive field. A unit in a deeper layer can depend on a larger part of the original image because it combines information that has already been combined by earlier layers.

This is how CNNs can build from local patterns toward larger and more global patterns.

### 4.6 Pooling

**Pooling** reduces the spatial size of a feature map. It is a lossy compression step because several nearby values are replaced by a smaller number of values.

Two common examples are:

- **Max pooling:** keep the maximum value in each pooling region.
- **Mean pooling:** replace each region by its average.

The lecture summarizes the main CNN ideas as:

- **Sparse connectivity:** each feature-map value uses only a small local patch.
- **Parameter sharing:** the same weights are reused at different spatial positions.
- **Many layers:** deeper layers combine local patterns into more global patterns.

The classic LeNet work is an early example of these ideas in a trainable image-recognition system. <d-cite key="lecun1998"></d-cite>

## 5. Cross-Correlation vs. Convolution

### 5.1 Convolution

For two independent random variables, convolution appears when computing the distribution of their sum. For continuous variables, the lecture writes the convolution as

$$
(P_X * P_Y)(z)
=
\int P_X(x)P_Y(z-x)\,dx.
$$

For a two-dimensional activation map \(A\) and kernel \(K\), convolution can be written as

$$
Z[i,j]
=
\sum_{u=-k}^{k}
\sum_{v=-k}^{k}
K[u,v]A[i-u,j-v].
$$

### 5.2 What Deep-Learning Frameworks Usually Compute

The operation commonly called "convolution" in deep-learning libraries is usually **cross-correlation**. Cross-correlation uses the kernel without flipping it:

$$
Z[i,j]
=
\sum_{u=-k}^{k}
\sum_{v=-k}^{k}
K[u,v]A[i+u,j+v].
$$

The main difference is the indexing. True convolution flips the kernel horizontally and vertically, while cross-correlation does not. In practice, neural-network libraries can still learn useful filters with cross-correlation because the filter values themselves are learned.

### 5.3 Output Size, Kernel Size, Padding, and Stride

The spatial output size depends on four quantities:

- \(W\): input width
- \(K\): kernel width
- \(P\): padding
- \(S\): stride

The lecture gives the output-width relationship as

$$
O
=
\frac{W-K+2P}{S}+1.
$$

For example, if \(W=28\), \(K=5\), \(P=0\), and \(S=1\), then

$$
O
=
\frac{28-5}{1}+1
=
24.
$$

So a \(28 \times 28\) input becomes a \(24 \times 24\) feature map for that convolution.

**Padding** adds values around the boundary of the input. It can help control how quickly spatial dimensions shrink. **Stride** controls how far the kernel moves between neighboring positions. A larger stride produces fewer output positions.

### 5.4 Translation, Rotation, and Scale

Weight sharing helps the same detector operate at different spatial positions, but the lecture emphasizes that CNN activations are still dependent on location. Therefore, CNNs should not automatically be treated as perfectly invariant to translation, rotation, or scale.

## 6. CNNs and Backpropagation

Backpropagation through a CNN uses the same multivariable chain rule as a fully connected network. The additional feature is **weight sharing**.

Because one kernel weight can be used at many spatial positions, the gradient for that shared weight receives contributions from every computation path in which the weight appears. The contributions are combined before the weight is updated.

### 6.1 A 1D Example

Consider the 1D cross-correlation

$$
z_k = w_1a_k + w_2a_{k+1},
\qquad k=1,2,3,
$$

where \(a\) has length 4.

Let

$$
\delta_k = \frac{\partial L}{\partial z_k}.
$$

Because one input value may contribute to more than one \(z_k\), its gradient is the sum of all relevant paths:

$$
\frac{\partial L}{\partial a_1}
=
w_1\delta_1,
$$

$$
\frac{\partial L}{\partial a_2}
=
w_2\delta_1+w_1\delta_2,
$$

$$
\frac{\partial L}{\partial a_3}
=
w_2\delta_2+w_1\delta_3,
$$

$$
\frac{\partial L}{\partial a_4}
=
w_2\delta_3.
$$

For the numerical example from lecture,

$$
w=(2,-1),
\qquad
\delta=(1,3,-2),
$$

which gives

$$
\frac{\partial L}{\partial a}
=
(2,5,-7,2).
$$

The lecture points out that this backward computation can itself be viewed as another convolution-like operation: zero-pad \(\delta\) and use the flipped kernel.

## 7. CNNs in PyTorch

PyTorch provides convolution and pooling layers through `torch.nn`. The lecture shows a LeNet-style network that alternates convolution, nonlinearity, and pooling before passing the extracted features into fully connected layers.

<d-code block language="python">
class LeNet5(nn.Module):
    def __init__(self, num_classes, grayscale=False):
        super(LeNet5, self).__init__()

        self.grayscale = grayscale
        self.num_classes = num_classes

        if self.grayscale:
            in_channels = 1
        else:
            in_channels = 3

        self.features = nn.Sequential(
            nn.Conv2d(in_channels, 6, kernel_size=5),
            nn.Tanh(),
            nn.MaxPool2d(kernel_size=2),
            nn.Conv2d(6, 16, kernel_size=5),
            nn.Tanh(),
            nn.MaxPool2d(kernel_size=2)
        )

        self.classifier = nn.Sequential(
            nn.Linear(16 * 5 * 5, 120),
            nn.Tanh(),
            nn.Linear(120, 84),
            nn.Tanh(),
            nn.Linear(84, num_classes)
        )

    def forward(self, x):
        x = self.features(x)
        x = torch.flatten(x, 1)
        logits = self.classifier(x)
        probas = F.softmax(logits, dim=1)
        return logits, probas
</d-code>

The convolutional part acts as an automatic feature extractor. After the convolution and pooling stages, the feature maps are flattened and passed to ordinary fully connected layers for classification.

## 8. Convolutions Beyond Images

The lecture ends by noting that convolution-style ideas are not restricted to image grids. Similar ideas can be extended to graph-structured data, leading to **Graph Convolutional Networks (GCNs)**. <d-cite key="kipf2016"></d-cite>

The exact neighborhood structure is different from an image grid, but the broader idea remains similar: combine information locally and reuse a structured operation across the data.

---

## 9. Summary

- **CNN applications:** CNNs can be used for image classification, object detection, and object segmentation.
- **Why not only fully connected networks?** Large images create a very large number of weights when every neuron connects to every pixel.
- **Filters and feature maps:** Small learned kernels slide across the input and create feature maps.
- **Sparse connectivity:** Each feature-map value depends only on a local receptive field.
- **Parameter sharing:** The same kernel weights are reused across spatial positions.
- **Depth:** Stacking layers lets receptive fields grow and allows local patterns to be combined into more global patterns.
- **Pooling:** Pooling reduces spatial resolution by summarizing local regions.
- **Cross-correlation vs. convolution:** Deep-learning libraries usually use cross-correlation even though the operation is commonly called convolution.
- **Output size:** Kernel width, padding, and stride determine feature-map dimensions.
- **Backpropagation:** CNNs use the same chain rule as other neural networks, but shared weights receive gradient contributions from multiple locations.
- **PyTorch:** CNNs can be constructed using layers such as `nn.Conv2d` and `nn.MaxPool2d`.
